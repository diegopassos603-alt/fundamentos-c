## 📂 Organização do projeto

### 01 — Variáveis

Exercícios relacionados à declaração de variáveis, tipos de dados e entrada e saída de informações.

### 02 — Operadores

Exercícios utilizando operadores matemáticos, relacionais e lógicos.

### 03 — Estruturas Condicionais

Exercícios utilizando:

* `if`
* `else`
* `else if`
* `switch`

### 04 — Estruturas de Repetição

Exercícios utilizando:

* `for`
* `while`
* `do while`

### 05 — Funções

Exercícios para praticar criação e utilização de funções.

### 06 — Vetores e Matrizes

Exercícios utilizando arrays unidimensionais e bidimensionais.
